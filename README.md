# Tübingen AI startup jobs

A focused, mobile-first board for open roles at AI startups from the Tübingen ecosystem.

The site is published through GitHub Pages. Its stable public entry point is intended to be `https://transfer.tuebingen.ai/jobs`.

## Local preview

```sh
python3 -m http.server 8766
```

Then open `http://127.0.0.1:8766/`.
